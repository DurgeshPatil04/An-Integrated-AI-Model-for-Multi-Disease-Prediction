# An-Integrated-AI-Model-for-Multi-Disease-Prediction
Machine learning-based system that predicts multiple chronic diseases — Diabetes, Heart, Kidney, Liver, and Stroke — using Random Forest and Neural Network models.
🧠 Overview

The Multi-Disease Prediction System is an intelligent healthcare application built using Machine Learning (ML) and Deep Learning (DL) techniques.
It predicts the likelihood of multiple chronic diseases — Diabetes, Heart Disease, Kidney Disease, Liver Disease, and Stroke — within a single unified platform.

This system utilizes Random Forest and Neural Network algorithms to deliver accurate and early disease predictions, enabling preventive diagnosis and supporting healthcare professionals in decision-making.

⚙️ Project Objective

To integrate multiple disease prediction models into one unified framework.

To improve early diagnosis accuracy using ensemble ML and neural networks.

To provide an easy-to-use graphical interface for clinical data input and real-time results.

To visualize model performance through graphs and confusion matrices.


🧰 Tech Stack

Programming Language: Python 3.10

Libraries: Pandas, NumPy, Scikit-learn, TensorFlow, Keras, Matplotlib, Seaborn

Framework: Flask / Streamlit (for web deployment)

Development Tools: Jupyter Notebook, Google Colab
